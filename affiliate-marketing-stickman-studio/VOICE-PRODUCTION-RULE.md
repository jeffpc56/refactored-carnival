# Voice Production Rule — CloneVoice

Approved October 16, 2026 by Jeff.

Use CloneVoice AI for Poppy's dialogue instead of the robotic/offline synthetic voice from the first prototypes.

- The Poppy character delivers all speaking narration.
- Use an authorized voice with natural conversational pacing, humor, timing and a friendly, slightly sarcastic sound.
- Voiceover exported from CloneVoice should be aligned to Poppy's visible lip movements.
- Stickmen on the TV behind Poppy silently mock him, timed to each spoken line.
- Keep room for pauses while Poppy turns toward the background TV.
- Do not present a basic computer-generated narration as CloneVoice audio.
- If CloneVoice output is not available via a connected integration, obtain Jeff's generated voice track and use it for the final render.
- Do not clone any voice without the speaker's authorization.
